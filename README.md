# 家電提案アシストPad

iPad Safariで使いやすい、家電販売店向けの接客補助Webアプリです。部門別カテゴリから商品一覧を確認し、メーカー・価格帯・タグで絞り込めます。必要に応じてカテゴリ別ヒアリングに進むと、回答タグと登録済み商品データを照合し、提案候補、接客メモ、最大3商品の比較表を表示します。

## 使っている技術

- HTML
- JavaScript
- Tailwind CSS CDN
- localStorage
- GitHub Pages

サーバー、外部API、Google Apps Script、npm、Vite、React、Vueは使っていません。

## ファイル構成

- `index.html`: 画面土台とTailwind CDN設定
- `script.js`: 画面描画、ヒアリング、比較、JAN検索、コピー処理
- `data.js`: 部門、カテゴリ、質問、商品データ
- `manifest.json`: ホーム画面追加向けの簡易マニフェスト
- `docs/`: 設計書
- `research/`: 商品調査メモ

## GitHub Pagesで公開する方法

1. このフォルダをGitHubリポジトリにpushします。
2. GitHubのリポジトリ設定で `Settings` → `Pages` を開きます。
3. Sourceを公開したいブランチの `/root` に設定します。
4. 表示されたURLにアクセスします。

## 商品データを追加する方法

`data.js` の `products` 配列に商品オブジェクトを追加します。

```js
{
  id: "sample_product",
  jan: ["4900000000000"],
  category: "hair-dryer",
  maker: "メーカー名",
  name: "商品名",
  modelNumber: "型番",
  productType: "提案しやすい商品タイプ",
  priceBand: "中価格帯",
  tags: ["quick-dry", "hair-care"],
  features: ["特徴1", "特徴2", "特徴3"],
  goodFor: "向いている人",
  caution: "注意点",
  hearingTips: ["確認ポイント1", "確認ポイント2", "確認ポイント3"],
  comparePoints: ["比較軸1", "比較軸2", "比較軸3"],
  talk: "接客で使える提案トーク",
  lastUpdated: "2026-07-04"
}
```

## カテゴリと部門

`data.js` の `departments` で、通信、情報、家電、季節AVの4部門を定義しています。カテゴリを追加するときは、`categories` にカテゴリを追加し、該当する `departments[].categoryIds` にカテゴリIDを入れてください。

カテゴリ画面では以下のフィルターが使えます。

- キーワード
- メーカー
- 価格帯
- 接客フィルター

ドライヤーでは、内部タグをそのまま表示せず、「早く乾かしたい」「広がり・パサつきが気になる」「重いのが苦手」など、接客中に使いやすい日本語ボタンで絞り込めます。

イヤホンでは、「ノイズキャンセリングあり」「インナーイヤー型」「耳をふさがない」「LDAC対応」「マルチポイントあり」などの接客フィルターを使えます。イヤホン商品には `specs` を追加し、装着方式、ANC、外音取り込み、コーデック、電池持ち、重量などを商品カードと比較表に表示します。公式確認できない仕様は `要確認` として表示しますが、機能ありの絞り込み条件には一致させません。

スマートウォッチでは、「健康管理をしっかり見たい」「睡眠を詳しく見たい」「スマホなしでGPS記録したい」「決済も使いたい」「軽くて寝る時も着けたい」などの接客フィルターを使えます。

プリンターでは、「写真をきれいに印刷したい」「インク代を抑えたい」「A3も印刷したい」「FAXも必要」など、印刷用途、ランニングコスト、用紙サイズ、仕事機能で絞り込めます。

## 比較リスト

商品比較は最大3件まで追加できます。比較画面から個別削除と一括リセットができます。比較リストの商品IDだけをlocalStorageに保存し、顧客情報やヒアリング回答は保存しません。

## JANコード登録ルール

JANコードは必ず配列で登録してください。同じ商品でも色違い、容量違い、販売パッケージ違いで複数JANになる可能性があります。

```js
jan: ["4549990000000", "4549990000001"]
```

## タグ命名ルール

タグは英小文字とハイフンのみで命名します。

良い例:

- `energy-saving`
- `large-capacity`
- `price-focused`
- `high-function`

避ける例:

- `省エネ`
- `EnergySaving`
- `energy_saving`
- `energy saving`

## 実運用前の注意

- 実運用前にJANコードと型番を正しい情報に差し替えてください。
- 顧客個人情報、実販売価格、在庫、社内情報は入力しないでください。
- このアプリは価格や在庫をリアルタイム取得しません。
- 調査時の価格や仕様は `research/dryer-products.md`、`research/earphone-products.md`、`research/smartwatch-products.md`、`research/printer-products.md` に記録していますが、アプリ上では価格帯のみ表示します。
- ドライヤー、イヤホン、スマートウォッチ、プリンターの `JAN未確認-...` は実JANではありません。実運用前に正規JANへ差し替えてください。

## カメラ読み取り機能

初期版ではカメラによるJAN読み取りは未実装です。将来的には `html5-qrcode` などを追加し、`script.js` の `startJanScanner()` を拡張できます。

## 方針

外部APIやGASを使わず、店頭のiPadで安定して開ける速度とシンプルさを優先しています。
